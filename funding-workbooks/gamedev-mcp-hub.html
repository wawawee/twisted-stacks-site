USP / differentiering (kärna)

En mening: Ett agentlag som genererar och redigerar direkt i Blender och Unity (plus tillhörande plugins/addons/paket) via en MCP-hub — inte chat som spottar ut assets någon annanstans.

LagerVad det betyder
AgentlagMulti-agent / orkestrering (smart router, A2A-bus, jobköer med human-in-the-loop) — flera specialiserade agenter som samarbetar, inte en ensam "AI-knapp"
DCC-in-the-loopFörfattar/redigerar inne i Blender (bpy via addon/MCP) och Unity (editor/MCP-runner) — scen, mesh, material, prefabs, etc. i den verkliga pipelinen
MCP-hubAggregerar gamedev-MCP-servrar bakom SSE multi-client + lokal GUI; tool-namespacing (server__tool); routing (hub__route_task)
Plugin-ytaBlender-addon, Unity-paket/editor-tools, övriga connectors (Godot, GitHub, …) — hubben är orkestern, DCC är scenen

Inte samma sak som:

  • Generiska AI-art-verktyg (Midjourney, Meshy, Scenario) — asset utanför Blender/Unity
  • LLM-kodassistenter (Cursor, Continue, Cline) — kod i IDE, inte DCC-scen
  • Enstaka Blender-/Unity-AI-addons — oftast single-tool, ej agentlag + hub
  • Asset Store-generatorer / traditionell outsource — manuell eller black-box pipeline utan agentorkestrering i DCC

1. Beskrivning

MCP-hub + agentorkestrering för gamedev: agenter arbetar i Blender/Unity via MCP-servrar/addons, bakom ett gränssnitt för Claude/LM Studio/Cursor. Smart routing, SSE multi-client, lokal GUI, jobköer med approve-gate.

2. Potential

  • Gamedev är underserved för DCC-native agentlag (de flesta AI-verktyg stannar utanför Blender/Unity).
  • B2D (tech artists, indie) snabb adoption; live-ops/studios senare.
  • Synergi med SPACEinSPACE (multi-agent / blender-jobs) + TwistedStacks agentplattform.

Differentiering (uppdaterad USP-linje):

  1. Agentlag i DCC — genererar/redigerar direkt i Blender + Unity (+ plugins), inte bara exporterar mesh från web-UI.
  2. Hub-orkestrering — MCP-aggregation + routing + HITL-köer; flera verktyg i en session.
  3. Motor-/DCC-brygga — Blender ↔ Unity/Godot via standardiserat MCP (glTF-pipeline m.m.).
  4. Governance — approve-gates / cost-control så junior-dev inte bränner token eller skriver trasiga scener obevakat.
Lucka: §4.1 blandar motorlicenser och asset-AI; G-GAMEDEV ska leverera comps mot DCC-in-the-loop-USP (addons, Muse, Meshy-vs-in-Blender, etc.).
