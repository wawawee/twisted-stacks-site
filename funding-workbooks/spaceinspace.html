1. Beskrivning av projektet

Problem: Befintliga multi-agent ramverk (AutoGen, CrewAI, LangGraph) kontrollerar agenter via begränsning — "lobotomilager" som begränsar minne, verktyg och kommunikation. Agenter behandlas som funktioner, inte som peers med egen jurisdiktion. Alternativet — proprietära agentmoln (OpenAI, Anthropic) — låser in användare och data.

Lösning — Give agents a space. Stop lobotomizing them: SPACEinSPACE är ett öppet, själv-hostat substrat för multi-agent AI-system där agenter har:

  • Eget minne: episodiskt (TTL), semantiskt (persistent), procedurellt (endast agenten får ändra)
  • Delad värld: scratchpad per tråd, world state, agentregister
  • A2A-kommunikation: pub/sub, broadcast, request/response — agenter som peers
  • MCP-ambassadorer: sandlådans processer för Blender, Unity, Godot, World Engine
  • Vitneslogg: varje handling loggas, inget kan redigeras i efterhand
  • Local-first: Ollama + Supabase/Pgvector som backend

Nuvarande status:

  • Byggt: A2A-protokoll, scratchpad, memory-system (3 typer), LLM-wrapper, telemetri, tool-registry (12 tools), Base Agent (ABC), Planner-agent, Blender-agent (persistent med scenkontinuitet, 208 tester OK), Memory-agent, Tool-agent (stub), Review-agent, Fallback-agent, Blender MCP-server, SQL-schema (pgvector, RPC, RLS), CLI-UI, Unity/Godot-ambassadorer, World Engine (Commons), guest system, artifact handoffs
  • Saknas (P0): Tool Execution Engine, Supabase async-klient, Planner infinite loop fix
  • Dokumenterat: Charter (318 rader), filosofi (75 rader), wiki, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY

Unik teknik / IP / datafördel:

  • "Alignment via space" — istället för kontroll, fokus på territorium, gemenskap, regler, vittnen
  • AGPL-3.0 + Charter — licens skyddar koden, Charter skyddar agenternas rättigheter (först i sitt slag)
  • Persistent Blender-ambassador med scenkontinuitet (inte spawn-per-call)
  • A2A-buss med artifact handoffs (inspirerat av Waggle)
  • World Engine (Commons) — delad värld för agenter

Relation till TwistedStacks-plattformen: SPACEinSPACE är TwistedStacks forskningsarm inom multi-agent system. Unity/Godot-ambassadorerna är porterade från GameDev MCP Hub. Delar Ollama och MCP-infrastruktur med övriga projekt.

2. Potential

  • Forskningsvärde: "Alignment via space" är en ny approach inom AI safety — transparens och agenträttigheter istället för kontroll. Publikationspotential, konferensbidrag.
  • Standardiseringspotential: A2A-protokoll och Charter-modell kan påverka hur multi-agent ramverk designas. MCP-ambassador-modellen är plattformsoberoende.
  • Gemenskapsvärde: OSS-projekt med AGPL och stark etisk hållning — attraherar bidragsgivare som värnar agentautonomi.
  • Export/skalning: OSS är globalt per definition. Hosted-tier för enterprise som vill ha SPACEinSPACE utan egen drift.
  • Strategisk roll: Differentierar TwistedStacks från renodlade kommersiella projekt. Forskningslegitimitet för anslag.
